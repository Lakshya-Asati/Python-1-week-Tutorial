# 🐍 7-Day Python Bootcamp

Welcome to the **7-Day Python Bootcamp**! This repository contains a structured, practical, and beginner-friendly roadmap designed to take you from writing your first line of code to building real-world Python applications.

---

## 📌 Course Structure Overview

| Day | Topic | Key Concepts | Daily Mini-Project |
| :--- | :--- | :--- | :--- |
| **Day 1** | **Setup, Variables & Types** | `print()`, Variables, Data Types, String Formatting, `input()` | 🧮 Tip Calculator |
| **Day 2** | **Control Flow & Logic** | `if / elif / else`, Comparison & Logical Operators | 🗡️ Text-Based Adventure |
| **Day 3** | **Loops & Data Structures** | Lists, Tuples, Sets, Dictionaries, `for` & `while` loops | 🔐 Password Generator |
| **Day 4** | **Functions & Scope** | Function definition, Parameters, Return values, Local vs Global scope | 📞 Contact Book |
| **Day 5** | **File I/O & Error Handling** | `try / except / finally`, Reading & Writing files (`open()`) | 📝 Persistent To-Do List |
| **Day 6** | **Object-Oriented Programming** | Classes, Objects, `__init__`, Attributes, Methods | 📚 Library System |
| **Day 7** | **Modules, APIs & Capstone** | `pip`, Importing modules, REST APIs with `requests` | 🌤️ Live Weather CLI App |

## 🚀 Getting Started

### Prerequisites
Before starting, ensure you have the following installed on your computer:
1. **Python 3.10+**: [Download Python](https://www.python.org/downloads/)
2. **Code Editor**: [VS Code](https://code.visualstudio.com/), PyCharm, or any editor of your choice.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/7-day-python-bootcamp.git
   cd 7-day-python-bootcamp
   ```

2. **Set up a virtual environment (optional but recommended):**
   ```bash
   # On Windows
   python -m venv venv
   venv\Scripts\activate

   # On macOS/Linux
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Install external dependencies (for Day 7):**
   ```bash
   pip install requests
   ```

## 🛠️ How to Use This Curriculum

1. **Daily Cadence:** Focus on one day at a time. Read the core concepts, run the sample code, and practice before building the daily mini-project.
2. **Modify & Expand:** Don't just copy the code—try adding new features or edge-case protections to each project!
3. **Commit Your Progress:** If using Git, make a commit at the end of each day to build your portfolio habit.
